# 🌌 BOOKHAVEN

**BookHaven** is a modern full-stack online bookstore designed to provide a smooth, immersive, and user-friendly digital shopping experience for book lovers.

The project combines a responsive **HTML5, CSS3, and JavaScript frontend** with a **Python Django backend**, **REST API architecture**, **JWT-based authentication**, and **MySQL database management**.

BookHaven is designed around the complete bookstore journey:

```text
        🔍 DISCOVER
             │
             ▼
        📚 EXPLORE
             │
             ▼
        📖 SELECT
             │
             ▼
        🛒 ADD TO CART
             │
             ▼
        🎟️ APPLY COUPON
             │
             ▼
        📦 PLACE ORDER
             │
             ▼
        ⭐ REVIEW
```

# 🚀 INSTALLATION

## 1️⃣ Clone the repository

```bash
git clone https://github.com/kriss2012/BookHaven-Website.git
```

---

## 2️⃣ Enter the project

```bash
cd BookHaven-Website
```

---

# 🐍 BACKEND SETUP

Move to the backend:

```bash
cd backend
```

Create a virtual environment:

### Windows

```powershell
python -m venv venv
```

Activate it:

```powershell
.\venv\Scripts\Activate.ps1
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

# 📦 INSTALL DEPENDENCIES

```bash
pip install -r requirements.txt
```

---

# 🗄️ DATABASE SETUP

Configure your MySQL database according to the Django project's database configuration.

Then run:

```bash
python manage.py makemigrations
```

```bash
python manage.py migrate
```

---

# 👤 CREATE ADMIN ACCOUNT

```bash
python manage.py createsuperuser
```

Follow the prompts displayed in the terminal.

---

# ▶️ RUN BACKEND

```bash
python manage.py runserver
```

The Django development server will start locally.

---

# 🌐 FRONTEND SETUP

The frontend is located inside:

```text
frontend/
```

Main files:

```text
index.html
styles.css
script.js
api.js
```

For API-driven functionality, serve the frontend through a local HTTP server rather than relying exclusively on a `file://` URL.

---

# ⚡ WINDOWS QUICK START

The repository contains:

```text
start.ps1
```

You can use the provided PowerShell startup script where appropriate:

```powershell
.\start.ps1
```

If PowerShell execution policies prevent the script from running, use the standard Django commands manually.

Before production deployment, make sure to configure:

* 🔐 Secure Django secret key
* 🗄️ Database credentials

* 🛡️ CORS

# 🎯 PROJECT OBJECTIVES

BookHaven was designed around several key objectives:

### 1. 📚 Improve Book Discovery

Create an intuitive digital environment where users can browse and search for books.

### 2. 🛒 Provide an E-Commerce Experience

Implement essential bookstore functionality such as carts, coupons, and orders.

### 3. 🔐 Implement Authentication

Provide user registration, login, and JWT-based API authentication.

### 4. 🔌 Build API-Driven Architecture

Separate frontend presentation from backend application logic through REST APIs.

### 5. 🗄️ Manage Structured Data

Use Django and MySQL to manage books, users, orders, reviews, and related data.

### 6. 📱 Deliver Responsive UX

Create a bookstore interface that adapts to different screen sizes.

# 🐛 BUG REPORTING

If you discover an issue:

1. Check whether the issue already exists.
2. Reproduce the problem.
3. Record your browser/device.
4. Describe expected behavior.
5. Describe actual behavior.
6. Include screenshots if useful.
7. Include console/API errors when relevant.
8. Open an issue on GitHub.

# 🛡️ SECURITY

If you discover a potential security issue, avoid publicly exposing sensitive information.

Do not commit:

```text
.env
SECRET_KEY
DATABASE_PASSWORD
JWT_SECRET
PRIVATE_KEYS
ACCESS_TOKENS
```

Use environment variables and secure production configuration.
